### How to use this template

1. Copy this file to `docs/adr/NNNN-kebab-case-title.md` with the next number.
2. Fill in every section; delete guidance text and unused optional fields.
3. Open a PR. The ADR starts as **Proposed** and becomes **Accepted** on merge.
4. Never edit an accepted ADR's decision: to change course, write a new ADR and
   set this one's status to **Superseded by** it.
