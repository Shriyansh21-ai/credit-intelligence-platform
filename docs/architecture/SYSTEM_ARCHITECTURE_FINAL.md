# System Architecture — Final (v1.0.0)

The AI Credit Intelligence Platform is a modular, additive, multi-tenant
enterprise banking platform. It grew across Phases 1–11 and Tracks 1–4, each
layer strictly additive over the last.

## Layered architecture

```
┌───────────────────────────────────────────────────────────────────────┐
│  Frontend (TanStack Start / React)                                     │
│  features/* + routes/* + global ⌘K command palette + sidebar sections  │
├───────────────────────────────────────────────────────────────────────┤
│  API layer (FastAPI)  —  every router RBAC-gated                        │
│  /api/* core · /api/ml · /api/saas · /api/ai · /api/os · /api/aip       │
│  /api/fin (Track 3) · /api/ent (Track 4)                               │
├───────────────────────────────────────────────────────────────────────┤
│  Services (pure/deterministic where possible)                          │
│  enterprise_assessment · ml · autonomous · banking_os · ai_platform    │

├───────────────────────────────────────────────────────────────────────┤
│  Persistence (SQLAlchemy ORM + Alembic)                                │
│  core tables + phase/track tables (aip_*, fin_*, ent_*, os_*, …)        │

```

## Design invariants

1. **Additive-only.** No API, table, migration, auth or RBAC grant is ever
   removed. Every track appends routers to a `ROUTERS` list mounted in `main.py`.
2. **Deterministic core.** Analytics/quant/productization services are pure and
   stdlib-only; Monte-Carlo uses a seedable RNG. Results carry SHA-256 checksums.
3. **Grounding-first AI.** LLM narratives phrase deterministic facts; every AI
   response carries confidence, reasoning, citations and evidence.
4. **Multi-tenant.** Nullable `tenant_id` on every additive table; `_tenant()`
   resolves the current tenant uniformly.
5. **RBAC everywhere.** Every route calls `require_permission("<scope>")`; the
   catalog is the single source of truth, synced to the DB.
6. **Reversible migrations.** Every migration is metadata-derived and reversible;
   one linear head at all times.

## Request lifecycle

Request → auth dependency → `require_permission` → tenant resolution → service
(deterministic compute + persistence) → JSON response. Mutating requests are
recorded by the audit middleware. Grounded results embed a checksum for
reproducibility.

## Frontend architecture

TanStack Start with file-based routing (`routeTree.gen.ts` auto-generated by the
router plugin at build). Each track ships a `features/<track>/` module (api.ts +
hooks.ts + index.ts) and `routes/<prefix>-*.tsx` pages, wired into the sidebar.
A single global `CommandPalette` provides ⌘K navigation across all modules.
